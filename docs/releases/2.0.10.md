# Zero3 2.0.10 · 状态栏单位跟随实体属性与头部米家状态修复

<!-- OTA_NOTES: 状态栏数值单位改为拼接传感器自身 unit_of_measurement,不再硬编码,不再重复|头部米家连接状态修复:直连/云连接正常时显示绿色,不再恒灰|实体选择抽屉去默认过滤全池展示,计数自解释(命中/全池),已绑定实体显示名称|仪表盘 HA 设备数首拍前显示「同步中」 -->

- 状态栏数值单位改为拼接传感器自身的 `unit_of_measurement`：不再硬编码 `°`/`%`，也不再与模板静态单位文本重复（此前显示 48°°C / 68%%）。单位随绑定实体自动变化——绑温湿度显示 °C/%，绑 PM2.5 显示 μg/m³，绑 CO₂ 显示 ppm。
- 模板静态单位文本（°C/%/μg/m³/ppm/mg/m³）由 UI 层动态隐藏，避免与读数内单位重复或张冠李戴。
- 头部「米家云」连接状态修复：状态 JSON 缓冲扩容（384→768 字节），此前缓冲不足导致米家状态从未上报、恒灰；直连/云连接正常时即显示绿色。
- 实体选择抽屉去掉各入口默认过滤：状态栏传感器、物理按键、人在唤醒、卡片绑定一律展示全池实体，自行搜索选择；计数自解释为「命中数 / 全池数」。
- 人在唤醒已绑定标签显示实体名称（此前因实体池异步加载晚于绘制而永远显示 entity_id）。
- 仪表盘「HA 设备」数在首次同步完成前显示「同步中」（该数值来自 HA 模板查询，每 10 分钟节流一次，空值期不再显示 `--`）。
- 排版属性抽屉标题即时跟随所选对象；「添加组件」按钮死区修复；实体选择抽屉跨页可用。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.10.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.10-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。
