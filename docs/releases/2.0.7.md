- 修复升级空间不足后无法重试、继续显示旧错误的问题；日志区分查询失败和实际空间不足，显示可用量、需求量和错误码。

- 硬链接不可用时预留复制与恢复空间；完全恢复成功的失败事务清理自身重复快照，恢复失败则保留材料。
- 一键安装继续支持最新版、多源代理及多个自定义代理；安装结束清理下载文件，避免重复解压校验。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.7.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.7-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。
