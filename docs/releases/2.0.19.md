# Zero3 2.0.19 · 米家本地中枢连接失败精确归因

<!-- OTA_NOTES: 米家本地中枢连接失败时记录具体原因(会话变更/账号不一致/配置损坏/存储失败),不再只有笼统提示,便于一次定位 -->

- **米家本地中枢连接失败精确归因**：
  - 此前本地中枢(局域网直连)连接失败时,日志只有一句笼统的「会话变更或存储失败」,无法判断真实原因。本版把身份绑定的全部失败路径拆开记录。
  - 新增诊断日志(设备日志 `[mijia-id]` 行 + 面板黑匣子事件):
    - 会话变更:标注是令牌/UUID/虚拟 did 中哪一项在验证窗口内发生了变化(此类下一轮自动恢复)。
    - 账号不一致:分别给出设备已存账号 ID 与云端解析的账号 ID(换账号/共享家庭场景)。
    - 配置落盘失败:配置文件缺失/损坏/超限、磁盘会话与内存不一致、备份/写入/替换各失败点均带系统错误码(满盘会显形)。
  - 中枢网关探测成功的瞬间也会记录其来源/IP/设备号——「中枢可达、身份未过」与「中枢不可达」从此在日志里一眼可分。
  - 令牌是凭据:日志只记录长度与前 6 字节,不落全量。
- 若设备日志出现「磁盘 user_id 与云端账号不一致」或「磁盘会话不匹配」,在该设备的 Web 集成页重新登录米家账号即可修复(生成全新配置,身份自然一致)。
- 延续 2.0.18:实体键四键全可用、设备端中文拼音输入。

## 安装

- 在线:Web「配置备份与升级」检查更新、下载,再确认安装。
- 离线:上传 `zero3-2.0.19.signed.tar.gz`,由设备验证后安装。
- 完整部署:解压 `zero3-2.0.19-full-deploy.zip`,将整个目录传入设备,执行 `sh install.sh --check`、`sh install.sh`,然后重启。
- 一键入口:发布仓 README 中下载并执行 `installer.sh`,自动获取当前最新版。
- **1.x 老设备**:直接用完整部署包或一键入口升级到本版;升级会替换应用层,账户、授权、Wi-Fi、布局与卡片配置保留。

## 升级前提醒

在线 OTA 需要 `/data` 至少有约 40MB 可用空间(2.0.15 起不足时直接报错并说明需要多少)。长期使用后可在文件管理里清理 `/data/deployment-backups`、旧 `ota-before-*` 目录后再升级。
