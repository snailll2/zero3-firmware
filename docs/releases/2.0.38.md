# 2.0.38

## 投屏页移动端布局
- 修复移动端投屏页面板下方空一条、预览左右留空：`.page` 在移动端有 `padding-bottom:96px`，投屏页是定高 flex 列，这段 padding 成为死区，stage 被压矮后 1024:600 画面按高度 contain，宽度也随之缩小（630×600 实测预览仅 453px）。
- 现在 `#page-monitor.active` 去掉底部 padding，面板撑到页面底部，预览恢复满宽（实测 574×336，原 453px）。
- 桌面/大屏布局不变。
