# 2.0.42

## 整屏背景图
- 设计器「屏幕属性 → 背景显示方式」启用**背景图片**：可从内置预设或本地上传（自动缩放 ≤1024×600、超 600KB 逐级降采样），保存后设备**整屏生效**——状态栏、导航栏、卡片区都叠在图上方。
- 设备端改用专用图像层（COVER 铺满 + 最底层），并修复两个 LVGL 限制：背景图透明度默认为 0 导致永不绘制、样式背景图只按原尺寸居中不缩放。
- 切回渐变/纯色会自动清除并删除设备上的图片文件；无自定义的背景屏保持原设置不变。

## 卡片外观
- **文字三色**：标题、副标题/状态行、控制区文字可分别设色（原来名称颜色字段在设备端从未生效）。
- **图标颜色**：卡片图标与图标盒底色同源可设置。
- **背景透明度**：卡片底色新增 0–100% 不透明度滑条，可透出整屏壁纸（0% 完全透明只显文字）。卡片的开启态/关闭态背景此前在实体卡上未生效，本次一并修复。

## 状态栏与导航栏
- 状态栏设置改为**独立面板**（与设计器其它面板同款），内含「基础属性 / 外观属性」两个 Tab：
  - 基础属性：传感器项（图标、名称、绑定实体，最多 5 项）
  - 外观属性：**文字颜色**与**图标颜色**分开设置
- 导航栏文字/图标颜色可分别设置。
- **导航项去底色**：只有选中项有背景，未选中项直接透出壁纸。
- **连接状态指示**：在线态图标与文字统一跟随主题强调色（二者同色），未连接/异常仍保留橙红警示；状态栏图标色也可统一传感器图标。

## 语音对讲（SIP）
- **息屏来电自动亮屏**：来电时先点亮屏幕、再弹出来电弹窗（约 2 秒内亮屏，熄屏与屏保态均可唤起）。
- **通话音量设置**：系统设置新增扬声器/话筒音量滑杆，保存后实时写入语音引擎（无需重启通话服务）。

## 控制响应
- 控制队列深度 8→32（多步场景/连续点击不再丢动作）。
- 待回执上限 8s→1.5s（异常拖尾大幅缩短，局域网正常路径不变）。
- 发送线程由 15ms 轮询改为入队即唤醒。
- **场景可打断**：连续点场景卡时以最后一次为准，旧场景在延时步立即退出，不再叠加执行。
