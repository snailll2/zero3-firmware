# 2.0.37

## 排版/卡片布局修复
- **缓存屏不随能力更新重建**：启动时非活动屏的卡片按 `fan_step=0` 建好模型（只有预设、没有风速滑条），米家能力随后到达只刷新活动屏；切回缓存屏只做重排+状态同步，不会重建模型，导致“首页米家风扇卡没有风速”，而详情弹窗（现场构建）正常。
- 切缓存屏时逐卡比较能力签名：签名变化则删除并按新能力重建卡片（含 grid 位置、签名），未变化才走原重排/同步。
- 实测：首页米家风扇卡出现「风速 0%」滑条 + 「直吹风」预设；米家灯色温 4200K/4350K 正常。

- 排版设计器拖动/拖影/缩格/气候卡渲染修复
