# 2.0.48

## 日志：抑制默认噪声
- 内存环只保留有意义的事件：`DEBUG` 级记录默认**不进入**环（计数为
  `suppressed`，可在 `/api/system/logs` 响应里看到），开启临时诊断
  （`logging.json {"persist_info":1}`）后才进入。
- 黑匣子镜像分级：米家轮询回执、`[selopt]` 存储、属性缓存、超大实体跳过、
  discover commit 等逐秒细节降为 DEBUG；界面/控制/连接/错误仍为 INFO。
- 效果（206 实测）：环 `dropped` 从 1044 降到 0，第一页不再被轮询刷屏，
  可见 UI 卡片挂载、慢帧、连接变化等真实事件。
