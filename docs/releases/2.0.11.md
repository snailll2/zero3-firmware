# Zero3 2.0.11 · Web 控制台页面修复合流与设计器可用性

<!-- OTA_NOTES: Web 控制台全部页面修复进入发布源:属性抽屉标题同步、实体选择抽屉跨页与全池展示、添加组件按钮死区、状态栏编辑器与设备同步|动态卡片设计器三栏视口化、卡片尺寸放大、标题与工具栏修整|仪表盘统计空值期显示「同步中」 -->

- **Web 控制台页面修复全部合入发布源**：此前 OTA 包内页面来自工作区旧版，安装后网页会回退；本版起发布包内页面与实机验收版一致。
- 属性抽屉标题即时跟随所选对象（此前切换物理按键时标题滞后一拍）；屏幕名与卡片名输入时标题同步。
- 卡片属性子标签栏（基础属性/外观与显示/动态控件）钉顶，不再随内容滚动。
- 统一实体选择抽屉搬到顶层：系统设置「选择传感器」等跨页入口可用（此前因寄居在排版页节点内，非排版页打开时整节隐藏＝点了没反应）。
- 实体选择抽屉去掉各入口默认过滤：状态栏传感器、物理按键、人在唤醒、卡片绑定一律展示全池，自行搜索；计数自解释为「命中数 / 全池数」。
- 人在唤醒已绑定标签显示实体名称（此前因实体池异步加载晚于绘制而总是显示 entity_id）。
- 「添加组件」按钮在 1150~1620 窗口宽度的死区修复：显隐跟随面板停靠状态，不再出现无添加入口。
- 状态栏编辑器与设备 `/api/statusbar` 双向同步：编辑列表映射五槽位、同类去重、禁用保绑定、回读校验；启用/禁用项在设备上 60 秒内跟随，无需重启。
- 动态卡片设计器（Beta）三栏视口化修复：画布满屏空白与三栏塌陷根治；画布适配锚定视口量高并带过渡态守卫；卡片改尺寸放大，图标与电源按钮不再被截断，比例恒定 440:260。
- 设计器标题「卡片动态布局设计器 Beta」恢复显示（Beta = 设计阶段标识），工具栏六按钮合并单行，说明改为「暂未正式启用 · 功能设计中」。
- 仪表盘「HA 设备」数在首次同步完成前显示「同步中」（该值来自 HA 模板查询，10 分钟节流一次）。
- 物理按键「控制实体」默认显示实体名称；按键动作选项收敛为设备实际支持项。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.11.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.11-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。
