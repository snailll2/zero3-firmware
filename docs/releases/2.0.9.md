# Zero3 2.0.9 · 状态栏门控真机生效与动态卡片设计器视口化

- 状态栏五项传感器（温湿度 / PM2.5 / CO₂ / 甲醛）en 门控在真机生效：网页状态栏编辑器增删项随「保存设备排版」同步到设备，启停 60 秒内跟随，无需重启；禁用项保留绑定，重新启用即恢复。
- 状态栏 chip 改为左对齐连续排布：不再固定槽位均分宽度，启用几个即从左连续显示几个。
- 网页状态栏编辑器与设备 `/api/statusbar` 双向同步：编辑列表按图标映射五槽位，同类去重、禁用保绑定、回读校验、失败不落盘；加载布局时从设备反灌种子。
- 动态卡片设计器（Beta）三栏视口化修复：画布满屏空白与三栏塌陷根治，panelbody 回归流内布局并补定位锚点；画布适配改为锚定视口量高（自身高度不参与测量，无反馈回路），并带隐藏/过渡态守卫与多拍复测。
- 设计器卡片改尺寸放大、弃 transform 栅格化：图标、电源按钮等控件不再被截断，比例恒定 440:260；画布列加宽（160/228），卡片 528×312 尽量充满工作区。
- 设计器标题「卡片动态布局设计器 Beta」恢复显示（Beta = 设计阶段标识）；工具栏六按钮合并单行；说明改为「暂未正式启用 · 功能设计中」。
- 排版属性抽屉标题即时跟随所选对象（原切换物理按键时标题滞后一拍）；「添加组件」按钮在 1150~1620 窗口宽度的死区修复；实体选择抽屉搬出排版页节点，系统设置等跨页入口可用；按键「控制实体」默认显示实体名称。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.9.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.9-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。
