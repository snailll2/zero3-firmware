# 2.0.32

## 卡片背景图
- 全卡型支持：时钟 / 天气 / UDP / 命令 / 功能卡此前只有实体卡渲染背景图，网页预览却给所有卡型显示，造成"设计师里正常、设备上没生效"；现统一铺满整卡
- 严格裁剪在卡片圆角内：根卡片开 `clip_corner` 兜底，背景图按"外圆角-边框"同心裁剪，圆角处不再溢出或露白缝
- flex 卡型背景图设为不参与布局，避免背景占掉布局槽把正文挤走
- 文件缺失时写 `[cardbg] missing <path>` 日志，便于远程排障

## 离线实体
- 状态明确区分：`unavailable` → **设备离线**，`unknown` → **状态未知**（不再是笼统"未获取状态"）
- 离线时保留已缓存控件与数值，但整卡置灰、不可点（预设/滑条/电源不再"看起来可用"）
- 能力缓存：空调/风扇的档位表、percentage_step、preset/swing、温度量程、选中项在离线更新时不被清空，并持久化到 `/data/nx5_conf/intercom/climate_caps.bin`，面板重启后加载（magic+版本+结构体大小校验，60 秒脏写合并、原子替换）

## 天气图标
- 修复 SVG 云朵几何超出 64×64 viewBox 被裁切的问题（平底/右侧缺角）：多云/阴/雨/雪/雾/雷/冻雨全部重排，雨滴/雪花/雾线/闪电同步下移不出界

## OTA 自动检查
- 自动检查改为真正的每日 10:00 调度：条件变量睡到 `next_check`，移除 30 秒轮询；时钟跳变/时间未同步时最迟每小时重算；检查/下载/安装进行中不抢占。首次开启自动检查仍立即检查一次
- 更新提示弹窗的 OTA_NOTES 改为 4 条短句（服务端清单支持 4×128 字节），弹窗信息更完整
