# Zero3 2.0.15 · OTA 卡死自愈与息屏点击唤醒

<!-- OTA_NOTES: 在线升级增加安装前空间预检,空间不足直接报错而不再卡在"安装中"|新增 FLASHING 看门狗:安装器 5 分钟未重启自动复位为失败并显示真实原因|投屏/概览在设备息屏时点击画面直接唤醒,不再提示"禁止触摸" -->

- **在线升级不再"假卡死"**：
  - 安装前空间预检：拉起安装器前检查 `/data` 可用空间（payload + 16MB 门槛），不足时立刻返回「空间不足：在线安装至少需要 X MB 可用，当前 Y MB」，不再进入安装态。此前空间不足时安装器会静默退出且不重启，OTA 状态永久停在 `FLASHING`，后续检查更新全被拒绝。
  - 新增 `FLASHING` 看门狗：安装器拉起后若 5 分钟内没有完成重启（脚本提前退出等异常），自动复位为失败状态，并从安装器结果文件带出真实失败原因，检查/下载立刻恢复可用。正常安装会随重启结束，不会误判。
  - 升级失败原因现在会显示在 Web OTA 面板，不再只有转圈。
- 息屏状态下的投屏交互优化：设备息屏时点击投屏画面（或概览里的设备预览）直接发送唤醒，提示「设备息屏中，已发送唤醒；画面将自动恢复」，状态轮询检测到亮屏后自动重连 MJPEG；只有真正在连接中才提示「设备画面连接中，请稍候再触控」（替换原先的「禁止远程触摸」）。
- 延续 2.0.14：屏保按钮、息屏/屏保状态区分、状态栏传感器左对齐。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.15.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.15-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。
- **1.x 老设备**：直接用完整部署包或一键入口升级到本版；升级会替换应用层，账户、授权、Wi-Fi、布局与卡片配置保留。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。

## 升级前提醒

在线 OTA 需要 `/data` 至少有约 40MB 可用空间（本版会在不足时直接报错并说明需要多少）。长期使用后 `/data/deployment-backups`、旧 `ota-before-*` 目录可能占满空间，可在文件管理里清理旧备份后再升级。
