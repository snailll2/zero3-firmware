# Zero3 2.0.18 · 实体键全键可用与设备端中文拼音输入

- **实体按键重标定,四键全可用**：
  - 高速采样实测：本批面板的四颗实体键为四根独立行线，按下各自拉低——按键1=gpio38、按键2=gpio39、按键3=gpio40、按键4=gpio41。
  - 旧轮询沿用的引脚集不含 gpio38/39，按键1/2 的信号从未被读取（表现为按了完全没反应）。轮询已改按实测引脚重标，并对接缺失的 GPIO 自动导出。
  - 四键实按全链路验证：识别 → 分发 → HA 命令/页面动作全部生效。
- **设备端输入框新增中文拼音输入**：
  - 设置页所有文本输入框（按键名称等）弹出输入面板时，键盘打出的字母进入拼音条，候选条实时给出汉字/词组，点选即上屏。
  - 词库覆盖 GB2312 常用字 6763 字（400 音节）+ 设备命名常用词组 31 个（客厅/卧室/灯带/窗帘/空调/风扇/场景等，打 `keting` 直接出「客厅」）。
  - 「中/En」切换拼音与英文直输（密码类输入用 En）；「删除」按钮删除已上屏字符。
  - 修复拼音选字上屏乱码（LVGL 小端机 add_char 取字节缺陷，改走 UTF-8 整串插入）。
  - 输入面板加高（300→380），模式/删除按钮不再被键盘遮挡。
- 延续 2.0.17：授权管理 Web 入口、实体键 3/4、投屏多窗口、天气源优化。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.18.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.18-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。
- **1.x 老设备**：直接用完整部署包或一键入口升级到本版；升级会替换应用层，账户、授权、Wi-Fi、布局与卡片配置保留。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。

## 升级前提醒

在线 OTA 需要 `/data` 至少有约 40MB 可用空间（2.0.15 起不足时直接报错并说明需要多少）。长期使用后可在文件管理里清理 `/data/deployment-backups`、旧 `ota-before-*` 目录后再升级。
