## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.12.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.12-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。
- **1.x 老设备**：直接用完整部署包或一键入口升级到本版；升级会替换应用层，账户、授权、Wi-Fi、布局与卡片配置保留。
