# Zero3 2.0.14 · 屏保按钮、息屏/屏保状态区分与状态栏传感器左对齐

<!-- OTA_NOTES: 投屏工具栏新增「屏保」按钮(进入亮屏待机时钟,与熄屏分开)|投屏按设备状态区分显示:息屏时显示「设备息屏中」且不再转圈,屏保时照常显示实际时钟画面|状态栏传感器改为左对齐连续排布,关闭某项后不再留空位 -->

- 投屏工具栏新增「屏保」按钮（首页与熄屏之间）：调用新增的 `POST /api/act {op:"saver"}` 进入待机时钟页，屏幕保持点亮；「首页」或点按画面可退出。与原有「熄屏」互不替代。
- `GET /api/screen` 新增 `saver` 字段（向后兼容）：`{"on":1,"saver":0}` 正常、`{"on":1,"saver":1}` 屏保、`{"on":0,"saver":0}` 息屏。
- Web 投屏/概览按设备状态区分显示：息屏时主动停止拉流，占位层显示「设备息屏中 · 点击画面或按「唤醒」点亮」并隐藏加载转圈；屏保时照常显示实际画面并标注「设备屏保中 · 实时画面」；亮屏后自动恢复实时画面。状态 2.5 秒只读轮询，页面隐藏时暂停。
- 状态栏传感器改为左对齐连续排布：
  - 设备端模板 header 的 5 个传感器 chip 原为绝对坐标，关闭某项后会留下空位（如 CO2 关闭时 PM2.5 与甲醛之间空一格）。现在按启用顺序自动前移，启用 N 项即从左连续 N 项。
  - 网页排版预览的传感器区由等分网格改为左对齐弹性排布，窄屏只压缩间距，不再均分留白。
- 屏保/熄屏与状态栏布局均不影响原有休眠策略：手动屏保仍按「自动息屏时间」转熄屏；传感器显隐、名称与图标配置保留。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.14.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.14-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。
- **1.x 老设备**：直接用完整部署包或一键入口升级到本版；升级会替换应用层，账户、授权、Wi-Fi、布局与卡片配置保留。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。
