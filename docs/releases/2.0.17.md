# Zero3 2.0.17 · Web 授权管理

<!-- OTA_NOTES: 设置页新增授权管理:授权状态/功能模块/有效期/机器码与激活码激活,失败会显示具体原因|授权管理手机宽度适配,激活按钮不再超出屏幕 -->

- **设置页新增「授权管理」**（设备控制分区）：
  - 此前授权激活只有设备端后端接口，网页控制台一直没有入口；设备端设置页提示「授权请使用 Web 管理端」却无处可用，本版补齐。
  - 授权状态一目了然：已激活/未激活、功能模块许可位（HA 集成 / 米家集成）、有效期（「永久有效」表示凭证无到期时间）。
  - 机器码展示与一键复制，向发行方申请授权凭证时直接提供。
  - 激活码激活：粘贴发行方提供的授权码即可激活，成功后设备界面自动重建；失败会显示后端给出的具体原因（机器码不符 / 授权已过期 / 凭证无效），不再只有笼统报错。
  - 手机宽度适配：激活按钮与输入框纵向排布，不再超出屏幕边界。
- 说明：离线授权文件导入的网页入口本版暂未提供（后端接口保留，后续按需补齐）。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.17.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.17-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。
- **1.x 老设备**：直接用完整部署包或一键入口升级到本版；升级会替换应用层，账户、授权、Wi-Fi、布局与卡片配置保留。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。

## 升级前提醒

在线 OTA 需要 `/data` 至少有约 40MB 可用空间（2.0.15 起不足时直接报错并说明需要多少）。长期使用后可在文件管理里清理 `/data/deployment-backups`、旧 `ota-before-*` 目录后再升级。
