- **空调模式/风速按设备实际档位展示**：
  - 档位权威源切换为全量实体接口（`/api/states`，每分钟批量刷新）：`hvac_modes`/`fan_modes` 等完整 attributes 逐实体吸收进能力表，空调详情与卡片下拉按设备真实档位展示（实测 5 模式 4 风速全出）。
  - 修复档位被吞的步长错位缺陷：实体值宽从 32 扩到 48 字节后，能力表读取处的行指针仍按旧 32 字节步进，读出稀疏空串导致 5 档只剩 2 档。行宽已与结构体对齐。
  - WS 实时推送若携带裁剪后的档位子集（实测网关事件把 5 模式裁成 制冷/送风），UI 侧不再回退覆盖，档位表只增不减。
  - 详情弹窗模式/风速改为两列下拉选择，展开列表与按钮均使用中文字体；段位控件档位较多时自动切换为下拉形态。
- **全部滑条旋钮与轨道两端对齐**：设置页亮度条、弹窗数值滑条、卡片亮度/色温/风速滑条、窗帘位置滑条统一为 0%/100% 时旋钮边缘贴齐轨道两端、不越出轨道边界，数值按此行程映射。设置页亮度条轨道加粗（10→14px），并消除左端始终露出的灰色圆帽（改为三层绘制：轨道/随值延伸的填充/旋钮）。
- **投屏多窗口观看**：投屏与首页快照共用设备端单路 MJPEG。此前两个窗口同时观看会互相顶流、轮流显示「等待设备画面」。现在自动重连改为礼貌等待（不顶流，被占用时提示「其他窗口可能正在观看 · 点击画面接管」），只有打开页面、点刷新或点击画面才显式接管；对方关闭后自动接上。
- 卡片状态行 HVAC 原始状态显示中文（制冷中/送风中/除湿中/自动冷热等）。
- 延续 2.0.15：屏保按钮、息屏/屏保状态区分、息屏点击唤醒、OTA 空间预检与 FLASHING 看门狗。

## 安装

- 在线：Web「配置备份与升级」检查更新、下载，再确认安装。
- 离线：上传 `zero3-2.0.16.signed.tar.gz`，由设备验证后安装。
- 完整部署：解压 `zero3-2.0.16-full-deploy.zip`，将整个目录传入设备，执行 `sh install.sh --check`、`sh install.sh`，然后重启。
- 一键入口：发布仓 README 中下载并执行 `installer.sh`，自动获取当前最新版。
- **1.x 老设备**：直接用完整部署包或一键入口升级到本版；升级会替换应用层，账户、授权、Wi-Fi、布局与卡片配置保留。

已有账户、授权、Wi-Fi、布局、场景和自定义卡片配置保留。此包是应用层完整部署，不是内核或分区镜像。

## 升级前提醒

在线 OTA 需要 `/data` 至少有约 40MB 可用空间（2.0.15 起不足时直接报错并说明需要多少）。长期使用后可在文件管理里清理 `/data/deployment-backups`、旧 `ota-before-*` 目录后再升级。
