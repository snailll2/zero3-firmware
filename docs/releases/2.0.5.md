## 使用

完整重装下载 `zero3-2.0.5-full-deploy.zip`，解压后把整个目录传到设备，运行 `sh install.sh --check`、`sh install.sh`，再执行 `reboot`。

已支持新升级引擎的设备可在 Web「备份与升级」检查在线更新，或上传本版 `zero3-2.0.5.signed.tar.gz`。完整部署 ZIP 不是离线上传文件；旧版尚不支持新接口时，首次迁移使用完整包安装。
