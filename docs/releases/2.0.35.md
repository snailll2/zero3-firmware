# 2.0.35

## 排版设计器 • 拖动

- **拖影不再放大**：原生拖拽的拖影按未缩放布局生成，画布 `scale` 后视觉约放大 2 倍；canvas 方案在高 DPI 下又会被 dpr 再放大一次。现改为原生拖影使用 1×1 透明图（预加载），另用 DOM 自绘拖影，宽高严格等于卡片屏幕尺寸。
- **拖影以拖拽点为卡片中心**：`left/top = 光标 - 宽高/2`，不再是左上角贴光标；顺带修复首帧 `display:none` 导致宽度为 0、第一帧仍按左上角定位的问题。
- **恢复原生 draggable**：PC 端原生拖拽手感不变，Android Chrome 长按原生拖拽同步恢复；落点列/行按卡片跨度夹取，拖到画布边缘或格子间隙不再静默失败。
- 之前"松手后卡片没落到目标格"的真因并非拖拽方式，而是落点后的 `renderScreens()` 被气候卡小尺寸渲染异常打断；该异常已修复。

## 排版设计器 • 网格

- 调低行/列时不再整表回退：保留仍然合法且不重叠的卡片位置，其余按顺序装进空格；跨格尺寸自动夹到新网格。
- 卡片数量确实放不下时明确提示，例如「该屏 9 张卡片放不进 3×2（容量 6）」，不再只提示"请先移动卡片"。
- 修复网格校验回退后，捕获阶段监听把非法网格写入内部状态的问题。
- 修复气候卡在小尺寸（如 8×8 网格 64×31）时布局函数提前返回、渲染读取 `undefined.x/h` 抛错并中断整个画布重建的问题。
