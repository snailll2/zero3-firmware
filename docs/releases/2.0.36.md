# 2.0.36

## 米家直连能力补齐（不依赖 HA）
- **风扇**：按 MIoT `fan-level` 值域提供风速（cfan 1–100，三档设备 33/66/100），预设模式（直吹风/自然风/循环风/睡眠）来自 `mode 4.7` 值表；修复 mode 值 4（睡眠）被丢弃
- **number**：米家 98 个数值属性按 `value-range` 提供 min/max/step/unit，详情滑条可调
- **媒体**：电视音量/静音/输入源（TV/DTMB/AV/HDMI 1–3）/播放暂停；音箱播放暂停/上下曲/音量/静音；属性与动作直接按设备 spec 挂到主实体
- **通知/TTS**：米家 `notify` 实体 `send_message` → play-text action，文本进 `in[0].piid=1`
- **灯**：色温量程与当前值来自 spec `color-temperature` value-range，灯卡不再显示 0K（实测 4200K/4350K，量程 3000–5700）
- **窗帘**：内部 `COVER_POS/COVER_STOP` 映射为 HA `supported_features`，详情恢复“位置 + 打开/停止/关闭”
- **扫地机**：吸力档位（安静/标准/强力/全速）与开始/暂停/停止/回充/定位动作已按 spec 挂接；本机 Roborock 在米家云离线，状态未知时 UI 按规则隐藏动作
