# 2.0.31

## 媒体播放器
- 详情弹窗重设计为播放器版式：正在播放内容（media_title / 艺术家，直播类无曲目回落显示输入源）+ 上一首 / 播放暂停 / 下一首 矢量图标键（播放中自动切换暂停图标，按 HA supported_features 显隐）
- 音量滑条统一为设备既有 cap 样式（灰轨 + 主题色填充 + 白底描边圆钮，两端对齐），替换旧渐变轨道+环形钮
- 静音 / 取消静音、输入源切换（source_list 原样、JSON 转义）；媒体卡大字改为显示当前播放内容
- 修复音量/静音触屏无效：滑条绑定曾挂在 NULL 对象上（slider() 返回 lv_slider 本体、无子对象）

## notify 通知域
- 新增 notify 卡片「发送通知」+ 详情弹窗按钮，服务固定 `notify.send_message`
- 通知内容在 Web 设计器实体卡中配置（组件 command 字段，留空用默认文案）；只允许发送给卡片绑定的 notify.* 实体
- 专属卡片版式（无电源钮/无值行）；设计器域名、实体筛选、图标同步补齐

## 控制域补齐
- **cover**：按 HA supported_features 显隐 位置/开/停/关（详情弹窗、免费卡、旧弹窗三路径）——仅支持 position+stop 的晾衣机不再显示会失败的开关按钮
- **风扇档位**：统一换算（档数=round(100/step)、档位=step 整数倍、顶档=100），消除弹窗 33/66/99/100 四档重复；native 改就近吸附（实测 33.33% 净化器只认 33/66/100）
- **number / select**：真实 min/max/step（含小数）、options 原样；**input_number / input_select** 收编为可控域（动态量程、选项侧表、native 白名单放行）
- **automation / button / scene**：开关、立即触发、按下执行、场景执行
- **light**：色温严格使用控件真实 Kelvin 量程（无假 2000-6500 映射）；颜色按 supported_color_modes 自适应 hs/rgb，保留当前饱和度；带参命令直连 HA 不再被插件路由吞掉
- **climate**：目标温度真实 min/max/step（16-32 实测可达 32）；能力元数据在 WS 轻量事件后不再丢失

## 修复
- 全站滑条 NULL 绑定：卡片内联亮度/色温/色相、风扇百分比、窗帘卡滑条、旧弹窗滑条行此前事件回调与量程设置全部挂在 NULL 上（显示正常但拖动无效），统一改为直挂 lv_slider 本体
- 详情弹窗点遮罩关闭；关闭路径清理残留手势闸门，避免弹窗刷新被永久阻塞
- Web 实体属性详情直接用发现阶段缓存的全量 attributes（不再实时查询、字段不再缺失）
